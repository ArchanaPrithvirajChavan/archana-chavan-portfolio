# Archana Chavan Portfolio

A responsive React + Vite portfolio website for Archana Chavan.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
This project can be deployed to Vercel, Netlify, or GitHub Pages.

Before publishing, replace the placeholder GitHub and LinkedIn links in `src/main.jsx` with your real profiles.

To add a resume PDF, place `Archana-Chavan-Resume.pdf` in the `public/` folder and add a link to `/Archana-Chavan-Resume.pdf`.
